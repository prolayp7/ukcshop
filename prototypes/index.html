UK Computer Shop · Phase 1

Six design directions for the storefront

Six directions, each covering the full shopping journey — home, category listing, product detail, brand, brand directory, basket, checkout and account — all built from the same catalogue data, so the comparison stays about design language and information density rather than content. Pick one, or tell me which parts of each to merge.

DIRECTION A

Highstreet

Mainstream UK e-tail · widest appeal

The familiar Scan / Overclockers / Currys shape, executed cleanly. Optimised for shoppers who already know how to buy from a big retailer.

  • Mega-menu navigation with promo panels
  • Scoped search with category dropdown
  • Hero carousel plus two promo cards
  • Dense 4-up product cards with specs, stock and VAT lines
  • Trust bar, countdown deals band, brand wall

DIRECTION C

Atelier

Editorial premium · trust & margin

Positions the shop as specialists rather than a price-comparison stop. Serif display type, generous space, guides from the workshop bench.

  • Centred wordmark with a calm secondary nav
  • Always-visible single-line search bar
  • Dark product-of-the-month spotlight with spec table
  • Quiet product grid — one clear price, no shouting
  • Journal/guides section supporting SEO and expertise

DIRECTION D

Spec Index

Search-first utility · live prototype

Treats the home page as the catalogue. The advanced search and filter requirements are the interface rather than a page you navigate to. This one is wired up — it runs against 104 dummy products.

  • Token search — socket:AM5, price:<200, vram:>=16
  • Facet rail built from the data, with live counts
  • Autocomplete, sorting, compare table, quick view
  • Filters are encoded in the URL, so a search is shareable
  • Zero dependencies — one JSON file and ~600 lines of vanilla JS

DIRECTION E · NEW

Voltage

Synthesis of the two reference sites

Built after reviewing Goxtore and Neotek. It takes the utility density of the first — support phone, order tracking, category→brand mega menus, off-canvas cart, countdown deals — and puts it on the editorial surface of the second: near-black and electric yellow, a search modal, category tiles carrying product counts, and generous spacing.

  • From Goxtore: utility bar with support number and order tracking, VAT/currency switchers, all-departments dropdown, category→brand mega menus, countdown deal band with stock-claimed bars
  • From Neotek: slim shipping-threshold announcement bar, ⌘K search modal, department tiles with live product counts, editorial build-room feature block, near-black + yellow palette, Lexend Deca
  • Added: off-canvas cart drawer that opens on every add, with live totals
  • Covers all eight page types like the other four

DIRECTION F · NEW

Ion

Ultra-modern · flagship launch

Same premium-tech register as a flagship product launch, dark canvas throughout with one signature neon rather than a multi-colour gaming palette. Rounded, glassy surfaces and soft glow replace angular clip-path cuts.

  • Two-column launch hero: bold claim, live stats, spotlight product card with real spec data
  • Unbounded display type, Manrope body copy, Martian Mono for spec labels — a typographic set not used anywhere else in the set
  • Single accent colour throughout (violet), used for focus states, prices and hover glow — no competing neons
  • Pill-shaped buttons and 14–24px corner radii instead of hard edges or angular cuts
  • Covers all eight page types like the other five

All six designs share one dummy catalogue (data/products.js, 104 products), one set of recommendation and compatibility rules (js/shop.js) and one basket/checkout implementation (js/commerce.js) — each design supplies only its own chrome, cards and stylesheet. The basket persists in localStorage; the checkout is a layout prototype that places no order and accepts no payment details. No build step, no framework. Pricing, stock and reviews are drawn from the shared dummy catalogue; company details shown are unmistakable placeholders pending real ones.
